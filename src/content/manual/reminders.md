<p>Omarchy has a built-in way to set simple reminders based on a countdown timer and with a message. You can do this via <code>Super + Ctrl + R</code>, seeing all the ones set via <code>Super + Ctrl + Alt + R</code>, and clearing all via <code>Super + Ctrl + Shift + R</code>. Everything also accessible via <em>Trigger &gt; Reminder</em>. You can also use the cli with <code>omarchy reminder 7 'Tea ready'</code>.</p>
