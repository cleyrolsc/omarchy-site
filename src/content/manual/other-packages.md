<p>Arch has an amazing wealth of packages available for almost any type of software between the official repository and the Arch User Repository (AUR).</p>

<p>It couldn’t be easier to use either. You install a new Arch package by going to <em>Install &gt; Package</em> in the Omarchy menu (<code>Super + Space</code>) and typing the package you want. It’ll automatically fuzzy filter the list of all packages. (You can also do it manually using <code>omarchy pkg add [package]</code> in the terminal).</p>

<p>You can do the same with AUR, just use <em>Install &gt; AUR</em>. Just remember that the AUR isn’t vetted by the Arch team. It’s like RubyGems or npm. Anyone can upload.</p>

<p>If you want to remove a package, you can use <em>Remove &gt; Package</em> from the Omarchy menu. It’ll remove package, config files, and dependencies. (You can also do it manually using <code>omarchy pkg drop [package]</code>).</p>
