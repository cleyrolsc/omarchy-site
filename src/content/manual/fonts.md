<p>Omarchy uses JetBrainsMono Nerd Font as both the terminal and system font by default.</p>

<p><img src="/manual/images/fonts-jetbrainsmono.webp" alt="fonts-jetbrainsmono" /></p>

<p>You can change this through the <em>Style &gt; Font</em> menu in the Omarchy menu (<code>Super + Space</code>). That sets the monospace font everywhere: the terminal, the bar, and anything else that asks for it.</p>

<p>You can install other popular programming fonts via <em>Install &gt; Style &gt; Font</em> in the Omarchy menu: Cascadia Mono, Meslo LG Mono, Fira Code, Victor Code, Bitstream Vera Mono, and Iosevka are all one click away, in their Nerd Font versions so the glyphs in the bar and terminal keep working. After installing one, pick it under <em>Style &gt; Font</em>.</p>
