<p>Omarchy comes with twenty-two beautiful themes. You can select between them via <em>Style &gt; Theme</em> in the Omarchy Menu (<code>Super + Space</code>) or hop directly to the theme selector using <code>Super + Ctrl + Shift + Space</code>.</p>

<p>Each theme styles the desktop, terminal, neovim, activity screen (btop), Chromium, and the entire Omarchy shell: top bar, menu, notifications, OSD, and the lock screen. (For Obsidian, you must manually select the Omarchy theme via <em>Appearance &gt; Themes</em> inside the app).</p>

<p>Themes have a set of background images that you can pick between using <code>Super + Ctrl + Space</code>.</p>

<p>You can find even more themes on <a href="/themes/">the extra themes page</a> or even <a href="/manual/making-your-own-theme/">make your own theme</a>.</p>
